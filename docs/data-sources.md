# データソース

## 出典

観光庁「インバウンド消費動向調査」（2024年1–3月期までは「訪日外国人消費動向調査」）。
2024年4–6月期から調査名が変わったが、推計方法は変わっておらず、観光庁はそれ以前と比べられるとしている。

公表の Excel 集計表は1人当たりの値だけで、国籍・地域別の旅行消費額（億円）は報告書・集計結果の PDF にしかない。
そのため、各年の年間値を公表した PDF と、当年の四半期の2次速報の PDF を読む。URL と読む表は `src/lib/data/sources.ts`。
都道府県は「都道府県別集計表」の Excel（表1-1・表1-3、全目的）。2024・2025年の年間 PDF【参考2】と四捨五入が一致することを確かめる。

- 2010–2018年、2020・2021年: 観光庁のサイトから消えているため、国立国会図書館 WARP の保存（2024-03-01）から取る。
- 2019年、2022年以降: 観光庁のサイトの現行の PDF。

各年の値はその年の資料の値を使い、後年の改訂は取り込まない（年の中の和が合うように）。
2012年はその年の資料で 10,861億円、後の資料では確定した訪日外客数で計算し直した 10,846億円。

## 読む表

| 表 | 内容 | ある年 |
| --- | --- | --- |
| 費目別 | 国籍・地域別の旅行消費額の総額と6費目（億円） | 2015–2019、2022– |
| 1人当たり | 国籍・地域別の1人当たり旅行支出（円）、旅行者数、旅行消費額 | 2010–2020、2023–2025 |

- 費目別の表は2018年以降、国籍・地域の行がクルーズ客を含む全体。1人当たりの表は2018年以降、一般客だけ。
- 2015・2016年の費目名は「宿泊料金」「娯楽サービス費」。正規化で現行の名前に揃える。
- 2020年は1人当たりの表の国籍・地域が一般客（和 7,409億円）で、全体の総額は 7,446億円。
- 2021年は総額（1,208億円）だけ。2022年は国籍・地域別の1人当たりがなく、全国籍の一般客の値だけ。
- 2010年の年間値は 4–12月の調査結果 8,823億円に 1–3月の推計 2,666億円を足したもの。1人当たり（133,766円）は 4–12月の平均。
- 2020–2022年は試算値。当年は四半期の2次速報を足して「1–◯月」の値とする。
- 国籍・地域の行は年によって増える（2014年にインドネシア・フィリピン・ベトナム、2015年にイタリア・スペイン、2026年にメキシコ・北欧・中東）。
- 都道府県別集計表は B1地域調査（一般客）。2018・2019年と2024年以降。2020年4–6月期から2023年1–3月期は中止、2023年は4–12月の参考値だけなので年間値はない。県の和は全国と一致しない（都道府県間交通費と訪問地不明を含まない）。

PDF は `pdftotext -layout` で読み、表の見出しを目印に、全国籍・地域の行から「その他」の行までを取る。
PDF の文字の割れ（例: `3 7 ,4 7 6`）は `sources.ts` の `repairs` で直し、直す対象が見つからなければ止める。

## パイプライン

1. `fetch` — PDF を `data/raw/{period}.pdf`、都道府県の表を `data/raw/{period}-pref.xlsx` へ（追跡しない）
2. `normalize` — 表を読み `data/normalized/docs.json` と `places.json` へ
3. `data` — 年×国籍・地域の配列 `public/data/spending.json` へ（型は `src/lib/data/cube.ts`）
4. `verify` — 次を確かめる（許容差は足した項の数の半分まで、四捨五入のため）
   - 費目の和が総額に一致する
   - 国籍・地域の和が全国籍・地域に一致する（総額と各費目）
   - 1人当たり×旅行者数が旅行消費額に一致する（1億円以内。2010年の全国籍は上記の理由で除く）
   - 2017年以前は、費目別の表と1人当たりの表の国籍・地域の総額が一致する
   - 都道府県は47県が揃い、訪問者数×消費単価と費目の和が総額に一致する
   - 2024・2025年は Excel を四捨五入した値が年間 PDF の【参考2】に一致する

## 配信データの決め方

- 国籍・地域の総額は、費目別の表がある年はその表、ない年は1人当たりの表の値。0行目（全国籍・地域）はどの年も全体の総額。
- 1人当たりは、1つの資料で年間値が出ている年だけ（当年の四半期は足せないので出さない）。
- 旅行消費額は、パッケージツアー料金のうち日本国内分を含み、日本との往復の国際運賃を含まない。日本に住む外国人は含まない。
